# Consultation delivery

The form uses native HTTPS POST to https://formsubmit.co/flawlessink112@gmail.com.
The visitor completes any provider CAPTCHA on the provider page. Gmail is not opened.
Activation and success are handled by FormSubmit; the website does not claim delivery.
Owner must confirm activation email and verify a labeled test reaches the inbox.
Reference links are supported; attachments are not currently offered.
Text fields are kept in tab session storage for return navigation, restored only within one hour, then removed. Storage failures do not prevent sending.
Native HTML validation also works without JavaScript. Call/SMS/email remain available.
