# Consultation conversion

The consultation form uses FormSubmit's native POST and its `_next` return URL.
The existing CAPTCHA and recipient activation flow are preserved.

After submission, FormSubmit redirects to:
`https://www.flawlessinkgallery.com/consultation-sent.html`

Google Ads setup for the existing **Request quote** action:

- Event: **Page load**.
- Match: **URL starts with** `www.flawlessinkgallery.com/consultation-sent.html`.
- Count: **One**, appropriate for lead requests per ad interaction.
- Keep the action primary if it is the intended campaign lead goal.

The confirmation page loads Google tag `AW-18508716792` only for the first
return carrying the random token generated by a validated form submission in
the same tab. It removes the token from the URL before loading the tag, consumes
the pending marker, and clears the saved form draft. Direct page visits, reloads,
invalid tokens, and tokens older than 24 hours do not load the tag. Storage-blocked
browsers can still submit but are not measured by this page.

This measures the completion of the provider's submission flow, not delivery
to the inbox, a confirmed appointment, or a paid booking. The provider return
is not a server-signed receipt. It must not be described as guaranteed email
delivery. Google Ads attribution, consent, and browser blocking can affect counts.

Validation: `node --test tests/consultation-confirmation.test.cjs` runs the actual
JavaScript with isolated form, history, and storage fixtures, including matching
and invalid provider returns. It sends no emails or analytics. A real end-to-end test still
requires completing the provider verification and confirming receipt at the
studio, after the Google Ads URL rule is saved.

Provider reference: https://formsubmit.co/ (the `_next` setting).
